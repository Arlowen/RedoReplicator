# Redo header layout baseline

`openlogreplicator-6bc92bc1.properties` is generated by
`scripts/baseline/run-redo-header-probe.sh` from the isolated
OpenLogReplicator source snapshot at commit
`6bc92bc1b89255fbc491e3080cb12a4c1dd8e832`.

The probe uses the pinned upstream `Ctx` byte readers and writers with a
deterministic synthetic Oracle 19c little-endian header. It records the file,
block, redo record and LWN fields used by the Java parsers. A second synthetic
big-endian header pins the native-word checksum behavior used by `Reader.cpp`.
